## Section Network Models and Physical Layer (ACtE0501)


## 📖 1. Introduction
Computer networking forms the backbone of modern communication and information systems. For the NEC license exam, understanding the fundamental network models and physical layer characteristics is critical. The physical layer is responsible for the actual transmission of raw bit streams over a physical medium, and it defines the electrical, mechanical, procedural, and functional specifications for activating, maintaining, and deactivating the physical link.

## 💡 2. Basic Concept
A computer network is a set of devices (often referred to as nodes) connected by communication links. A node can be a computer, printer, or any other device capable of sending and/or receiving data generated by other nodes on the network.

> [!NOTE] Definition
> **Topology**: The physical or logical arrangement of the links and nodes of a network. Common topologies include Star, Bus, Ring, Mesh, and Tree.

## 3. Network Models, Protocols, and Standards
To ensure different systems can communicate, network architectures are broken down into layers.

> [!NOTE] Definition
> **Protocol**: A set of rules governing data communication. It defines *what* is communicated, *how* it is communicated, and *when* it is communicated (syntax, semantics, and timing).

### The OSI Model
The Open Systems Interconnection (OSI) model is a theoretical 7-layer framework developed by ISO.

| Layer | Name | Primary Function | Data Unit |
|---|---|---|---|
| 7 | Application | Network access to applications (HTTP, FTP, SMTP) | Data |
| 6 | Presentation | Data translation, encryption, compression | Data |
| 5 | Session | Establishment, management, and termination of sessions | Data |
| 4 | Transport | End-to-end delivery, error recovery, flow control (TCP, UDP) | Segments |
| 3 | Network | Routing and logical addressing (IP, ICMP) | Packets |
| 2 | Data Link | Physical addressing, node-to-node delivery, framing | Frames |
| 1 | Physical | Transmission of raw bits over a communication channel | Bits |

### The TCP/IP Protocol Suite
The TCP/IP model is the practical framework on which the Internet runs. It consists of four layers:
1. **Application Layer**: Combines OSI Application, Presentation, and Session layers.
2. **Transport Layer**: Corresponds to OSI Transport layer.
3. **Internet Layer**: Corresponds to OSI Network layer.
4. **Network Access Layer**: Combines OSI Data Link and Physical layers.

## 4. Transmission Media
Transmission media can be broadly categorized into guided (wired) and unguided (wireless) media.

### Guided Media
Signals are guided along a solid medium.
- **Twisted-Pair Cable**: Consists of two insulated copper wires twisted together. Used in LANs (e.g., Cat5e, Cat6). Uses RJ-45 connectors.
- **Coaxial Cable**: Contains a central copper conductor covered by an insulating layer, a metallic braided shield, and an outer jacket. High bandwidth, used in cable TV.
- **Fiber-Optic Cable**: Transmits data via light pulses over glass or plastic fibers. Offers the highest bandwidth and is immune to electromagnetic interference (EMI).

### Wireless Transmission
Signals are broadcast through free space.
- **Radio Waves**: Omnidirectional, can penetrate walls. Useful for AM/FM radio, older TV.
- **Microwaves**: Unidirectional, requires line-of-sight. Used for satellite communications and mobile phone networks.
- **Infrared**: Short-range communication requiring direct line-of-sight (e.g., TV remote controls).

## 5. Bandwidth and Data Rate Limits
The data rate (capacity) of a channel is limited by its bandwidth and the presence of noise.

### Nyquist Bit Rate for Noiseless Channel
For a noiseless channel with bandwidth $B$, the maximum bit rate $C$ is given by:
$$C = 2B \log_2(L)$$
where $L$ is the number of signal levels used to represent data.

### Shannon Capacity for Noisy Channel
For a noisy channel, the theoretical maximum data rate (capacity) is given by Shannon's theorem:
$$C = B \log_2(1 + \text{SNR})$$
where:
- $C$ = Channel capacity in bits per second (bps)
- $B$ = Bandwidth of the channel in Hertz (Hz)
- $\text{SNR}$ = Signal-to-Noise Ratio (not in dB, absolute power ratio)

> [!NOTE] Definition
> **SNR in dB**: $\text{SNR}_{dB} = 10 \log_{10}(\text{SNR})$

**Example**:
Calculate the Shannon capacity of a channel with a bandwidth of 3 kHz and an $\text{SNR}_{dB}$ of 30 dB.
1. Convert SNR from dB to ratio: $30 = 10 \log_{10}(\text{SNR}) \implies \text{SNR} = 1000$
2. Apply Shannon formula: $C = 3000 \log_2(1 + 1000) \approx 3000 \times 9.967 \approx 29,901 \text{ bps}$.

## 💡 6. Switching and Multiplexing Techniques

### Switching
Networks use switching to route data from source to destination.
- **Circuit Switching**: A dedicated physical path is established for the duration of the connection (e.g., PSTN). Constant delay, guaranteed bandwidth.
- **Packet Switching**: Data is broken into packets. Each packet travels independently, potentially taking different routes. More efficient use of bandwidth (e.g., the Internet).
- **Message Switching**: The entire message is transferred from switch to switch using store-and-forward. Rarely used today.

### Multiplexing
Multiplexing allows multiple signals to share a single medium.
- **FDM (Frequency Division Multiplexing)**: Divides the channel bandwidth into non-overlapping frequency bands (e.g., Radio stations).
- **TDM (Time Division Multiplexing)**: Divides the channel time into discrete time slots allocated to different signals (e.g., T1 lines).
- **WDM (Wavelength Division Multiplexing)**: Essentially FDM for optical fibers; different data streams use different wavelengths (colors) of light.

## 💡 Common Mistakes / Exam Tips

> [!WARNING]
> Do not confuse $B$ in Shannon capacity (Hertz) with Byte ($B$). In networking formulas, $B$ stands for bandwidth in Hertz.
> Do not use SNR in dB directly in the Shannon formula; always convert it to the linear power ratio first!

> [!TIP]
> The OSI model layers are frequently tested. Remember the mnemonic "Please Do Not Throw Sausage Pizza Away" (Physical, Data Link, Network, Transport, Session, Presentation, Application).

## 📝 Quick Reference / Formula Summary

> [!IMPORTANT]
> - **Nyquist**: $C = 2B \log_2(L)$
> - **Shannon**: $C = B \log_2(1 + \text{SNR})$
> - **TCP/IP vs OSI**: TCP/IP has 4 layers, OSI has 7 layers.

## ✏️ Practice Problems

1. **Problem**: What is the theoretical maximum bit rate of a noiseless channel with a bandwidth of 4 kHz transmitting a signal with 4 levels?
   *Answer Sketch*: Use Nyquist formula. $C = 2 \times 4000 \times \log_2(4) = 8000 \times 2 = 16,000 \text{ bps}$.

2. **Problem**: Identify the OSI layer responsible for routing packets across distinct networks.
   *Answer Sketch*: The Network layer (Layer 3) handles routing and IP addressing.

3. **Problem**: Which multiplexing technique assigns a unique frequency band to each transmission?
   *Answer Sketch*: Frequency Division Multiplexing (FDM).
