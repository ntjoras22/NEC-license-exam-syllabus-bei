## Section 10.3 — Project Planning and Scheduling (AALL1003)

## 📖 1. Introduction
Project Planning and Scheduling are fundamental components of project management. They involve defining objectives, outlining tasks, allocating resources, and setting timelines. For the NEC exam, mastering network diagrams, critical path analysis (CPM/PERT), and resource management is essential.

## 💡 2. Basic Concept
Planning is deciding *what* to do and *how* to do it. Scheduling is deciding *when* to do it. 

> [!NOTE] Definition
> **Project**: A temporary endeavor undertaken to create a unique product, service, or result. It has defined start and end dates, specific objectives, and limited resources.

## 🏷️ 3. Project Classifications and Life Cycle Phases
### Classifications
Projects can be classified by scale (mega, major, medium, minor), sector (infrastructure, IT, R&D), or ownership (public, private, PPP).

### Project Life Cycle Phases
1. **Initiation**: Defining the project, feasibility studies, conceptualization.
2. **Planning**: Developing the schedule, budget, risk management plan.
3. **Execution/Implementation**: Carrying out the planned work.
4. **Monitoring and Controlling**: Tracking progress and making adjustments.
5. **Closure**: Handover, final reporting, releasing resources.

## 4. Project Planning Process
The planning process involves:
1. Setting project objectives.
2. Work Breakdown Structure (WBS): Decomposing the project into smaller, manageable components.
3. Defining activities and their sequences.
4. Estimating durations and resources.

## 5. Project Scheduling (Bar Chart, CPM, PERT)
### 5.1 Gantt Chart (Bar Chart)
A graphical representation showing activities as horizontal bars plotted against time.
- **Pros**: Easy to understand, good for reporting.
- **Cons**: Does not clearly show interdependencies between activities.

### 5.2 Critical Path Method (CPM)
CPM is a deterministic network analysis technique used to predict project duration by identifying the longest path of dependent activities.
- **Activity-on-Node (AON)** or **Activity-on-Arrow (AOA)** networks.
- **Critical Path**: The longest path through the network. It has zero float (slack). A delay here delays the entire project.
- **Float (Slack)**: The amount of time an activity can be delayed without delaying the project finish date.

$$ \text{Total Float} = \text{Late Start} - \text{Early Start} = \text{Late Finish} - \text{Early Finish} $$

### 5.3 Program Evaluation and Review Technique (PERT)
PERT is a probabilistic technique used when activity durations are uncertain. It uses three time estimates:
- Optimistic time ($t_o$)
- Most likely time ($t_m$)
- Pessimistic time ($t_p$)

**Expected Time ($t_e$) Formula:**
$$ t_e = \frac{t_o + 4t_m + t_p}{6} $$

**Variance ($\sigma^2$) Formula:**
$$ \sigma^2 = \left(\frac{t_p - t_o}{6}\right)^2 $$

**Worked Example 1: PERT Calculation**
An activity has $t_o = 2$ days, $t_m = 5$ days, and $t_p = 14$ days. Calculate the expected duration and standard deviation.
**Solution:**
$$ t_e = \frac{2 + 4(5) + 14}{6} = \frac{36}{6} = 6 \text{ days} $$
$$ \sigma = \frac{14 - 2}{6} = 2 \text{ days} $$

## 6. Resources Levelling and Smoothing
Projects often face resource constraints (labor, equipment, capital).
- **Resource Leveling**: Adjusting the schedule to prevent over-allocation of resources. It often extends the project duration. (Time is variable, Resources are fixed).
- **Resource Smoothing**: Adjusting activities within their free float limits so that resource usage is as uniform as possible without delaying the project. (Time is fixed, Resources are optimized).

## 7. Monitoring, Evaluation, and Controlling
- **Monitoring**: Continuous collection of project data.
- **Evaluation**: Periodic assessment of project relevance, performance, and impact.
- **Controlling**: Taking corrective actions based on variances between planned and actual performance (e.g., using Earned Value Analysis).

## 💡 Common Mistakes / Exam Tips

> [!WARNING]
> A common trap in CPM problems is forgetting that multiple critical paths can exist in a single network.

> [!TIP]
> In PERT, the expected project duration is the sum of $t_e$ on the critical path, and the project variance is the sum of variances (not standard deviations!) of critical path activities.

## 📝 Quick Reference / Formula Summary

> [!IMPORTANT]
> - CPM Total Float = $LS - ES$ or $LF - EF$
> - PERT Expected Time $t_e = (t_o + 4t_m + t_p) / 6$
> - Resource Smoothing does NOT extend project duration.

## ✏️ Practice Problems
1. The critical path in a project network represents:
   a) The shortest path through the network
   b) The longest path through the network
   c) The path with the most activities
   d) The path with the maximum float
   *Answer Sketch: b. It is the longest sequence of activities, determining the shortest possible project duration.*

2. If an activity has an early start of day 3, a late start of day 5, and a duration of 4 days, what is its total float?
   a) 2 days
   b) 4 days
   c) 8 days
   d) 0 days
   *Answer Sketch: a. Total Float = LS - ES = 5 - 3 = 2 days.*
