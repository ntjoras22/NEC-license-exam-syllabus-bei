# Section 2.4: Microprocessor (AExE0204)

## 📖 1. Introduction
The microprocessor is the heart and brain of any computing system. In the context of the NEC Registration Exam, understanding the internal architecture, features, and assembly language programming of the Intel 8085 microprocessor is crucial. The 8085 serves as the foundational 8-bit architecture from which modern processors have evolved, providing essential insights into instruction execution, bus architecture, memory interfacing, and hardware-software interaction. 

## 💡 2. Basic Concept
A microprocessor acts as a programmable logic device that reads instructions from memory, accepts binary data as input, processes data according to those instructions, and provides results as output. 

Imagine a head chef (the Microprocessor) in a kitchen (the Computer System). The chef reads recipes (Instructions) from a cookbook (Memory), gathers ingredients (Input Data) from the pantry (I/O devices), processes the ingredients by chopping and cooking (ALU operations), and finally serves the finished dish (Output Data) to the customer. The chef orchestrates the whole process using a set of rules and timing.

## ✏️ 3. Definition
> **Microprocessor:** A microprocessor is a multipurpose, programmable, clock-driven, register-based electronic device that is built on a single integrated circuit (IC), which reads binary instructions from a storage device called memory, accepts binary data as input, processes data according to those instructions, and provides results as output.

## 4. Physical/Logical Meaning
Physically, the 8085 microprocessor is a 40-pin Dual In-line Package (DIP) IC fabricated using N-MOS technology. Logically, it consists of three main units:
1. **Arithmetic and Logic Unit (ALU):** Performs mathematical and logical operations.
2. **Timing and Control Unit:** Generates timing signals to synchronize operations and control signals to manage data flow.
3. **Register Array:** Stores temporary data during execution.

## 5. Features of 8085 Microprocessor
The Intel 8085 is an 8-bit general-purpose microprocessor capable of addressing 64 KB of memory.

- **Data Bus:** 8-bit bidirectional.
- **Address Bus:** 16-bit unidirectional, capable of addressing $2^{16} = 65,536$ bytes ($64 \text{ KB}$) of memory.
- **Multiplexed Bus:** The lower 8 bits of the address bus ($A_0-A_7$) are multiplexed with the 8-bit data bus ($D_0-D_7$) as $AD_0-AD_7$ to reduce the number of pins.
- **Clock Frequency:** Operates at a frequency of 3 MHz (Requires a 6 MHz crystal, internally divided by 2).
- **Power Supply:** Single +5V DC power supply.
- **Instruction Set:** 74 distinct instruction types with a total of 246 opcodes.
- **Interrupts:** 5 hardware interrupts: `TRAP`, `RST 7.5`, `RST 6.5`, `RST 5.5`, and `INTR`.
- **Serial I/O:** Provides built-in support for serial communication via `SID` (Serial Input Data) and `SOD` (Serial Output Data) pins.

> [!NOTE] 
> The '5' in 8085 stands for the fact that it requires a single +5V supply, unlike the earlier 8080 which required multiple power supplies (+5V, -5V, +12V).

## 6. Internal Architecture of 8085 Microprocessor

### 6.1 Register Organization
The 8085 has a set of registers used for storing temporary data and memory addresses.

**General Purpose Registers:**
- The 8085 has six 8-bit general-purpose registers: **B, C, D, E, H, and L**.
- They can be used individually to store 8-bit data, or combined into register pairs to store 16-bit data or memory addresses: **BC, DE, and HL**.
- The **HL pair** acts as a default memory pointer (M).

**Special Purpose Registers:**
1. **Accumulator (A):** An 8-bit register connected to the ALU. It holds one of the operands during ALU operations and stores the result after the operation.
2. **Program Counter (PC):** A 16-bit register that sequences program execution. It always points to the memory address of the *next* instruction to be fetched.
3. **Stack Pointer (SP):** A 16-bit register that points to the top of the stack memory (a LIFO data structure in RAM).
4. **Instruction Register (IR):** An 8-bit register that temporarily holds the fetched opcode before it is decoded.
5. **Temporary Register:** An 8-bit register used internally by the microprocessor (not accessible to the programmer) to hold operands during ALU operations.

### 6.2 Flag Register
The Flag Register is an 8-bit register containing 5 flip-flops that indicate the status of the result generated by the ALU. 

| $D_7$ | $D_6$ | $D_5$ | $D_4$ | $D_3$ | $D_2$ | $D_1$ | $D_0$ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| S | Z | X | AC | X | P | X | CY |

*(X = Don't Care/Undefined)*

1. **Sign Flag (S):** Set (1) if the MSB ($D_7$) of the result is 1 (indicating a negative number in 2's complement). Reset (0) if positive.
2. **Zero Flag (Z):** Set (1) if the ALU result is exactly 0. Reset (0) if non-zero.
3. **Auxiliary Carry Flag (AC):** Set (1) if there is a carry from the lower nibble ($D_3$) to the higher nibble ($D_4$) during BCD addition. Used internally by the `DAA` instruction.
4. **Parity Flag (P):** Set (1) if the result has an even number of 1s (Even Parity). Reset (0) if it has an odd number of 1s (Odd Parity).
5. **Carry Flag (CY):** Set (1) if an arithmetic operation generates a carry out of the MSB ($D_7$), or a borrow during subtraction.

> [!IMPORTANT]
> The Zero Flag (Z) is set to 1 when the result is 0. This counter-intuitive naming often trips up students. Think of it as the "Is Zero?" flag.

### 6.5 Bus Structure
1. **Address Bus ($A_8 - A_{15}$):** Unidirectional, carries the higher order 8 bits of the 16-bit address.
2. **Multiplexed Address/Data Bus ($AD_0 - AD_7$):** Bidirectional. During the first clock cycle ($T_1$) of a machine cycle, it carries the lower 8 bits of the address. During subsequent clock cycles ($T_2, T_3$), it carries the 8-bit data. 
   - **ALE (Address Latch Enable):** A positive pulse generated during $T_1$ to latch the lower address byte externally.

## 7. Timing Diagrams and Machine Cycles

### 7.1 Definitions
- **Instruction Cycle:** The time required by the microprocessor to fetch and execute one entire instruction.
- **Machine Cycle:** The time required to complete one fundamental operation such as memory read, memory write, I/O read, or I/O write. An instruction cycle consists of 1 to 5 machine cycles.
- **T-State:** One subdivision of a machine cycle, corresponding to one clock period of the microprocessor's clock signal.

$$ T = \frac{1}{f} $$
  For a 3 MHz clock, $T = 1 / 3\times10^6 = 0.33 \mu s$.

### 7.2 Opcode Fetch Cycle
Every instruction starts with an Opcode Fetch machine cycle. The microprocessor fetches the opcode from memory. It usually requires 4 T-states ($T_1$ to $T_4$).

```text
Clock:      ___     ___     ___     ___
           |   |   |   |   |   |   |   |
      _____|   |___|   |___|   |___|   |___
T-States:    T1      T2      T3      T4

ALE:       ___
          |   |________________________
          _

AD0-AD7:  --< Lower Addr >--< Opcode  >----
          --<   (A0-A7)  >--< In      >----
A8-A15:   --<  Higher Address (A8-A15)>----
IO/M':     _________________________________ (Low for Memory)
RD':       _________             ___________
                    |___________|
```
- **$T_1$:** ALE goes high. $A_{8}-A_{15}$ gets higher address. $AD_0-AD_7$ gets lower address.
- **$T_2$:** ALE goes low. $RD'$ goes low. Memory outputs opcode on $AD_0-AD_7$.
- **$T_3$:** Opcode is transferred to Instruction Register. $RD'$ goes high.
- **$T_4$:** Microprocessor decodes the opcode. No bus activity.

### 7.3 Memory Read/Write Cycle
Requires 3 T-states ($T_1, T_2, T_3$). Similar to Opcode fetch, but $T_4$ is absent because no decoding is required. For write, $WR'$ goes low instead of $RD'$.

## 8. Assembly Language Programming

### 8.1 Instruction Format and Size
An instruction consists of two parts:
1. **Opcode (Operation Code):** Specifies the operation to be performed (e.g., MOV, ADD).
2. **Operand:** The data to be operated on (can be register, memory, or immediate data).

Instructions are classified by byte size:
1. **1-Byte Instruction:** Opcode and operand are in the same byte. (e.g., `MOV A, B`, `ADD B`).
2. **2-Byte Instruction:** 1st byte is Opcode, 2nd byte is 8-bit data/port address. (e.g., `MVI A, 05H`, `IN 80H`).
3. **3-Byte Instruction:** 1st byte is Opcode, 2nd and 3rd bytes are 16-bit address/data. The lower byte of the address is stored first (Little Endian). (e.g., `LDA 2000H`, `LXI H, 2050H`).

### 8.2 Addressing Modes
Addressing modes specify how the operand is provided to the instruction.
1. **Immediate Addressing:** The 8/16-bit operand data is specified directly in the instruction. (e.g., `MVI B, 45H`, `LXI H, 2000H`).
2. **Register Addressing:** Operands are in the general-purpose registers. (e.g., `MOV A, B`, `ADD C`).
3. **Direct Addressing:** The 16-bit memory address of the operand is explicitly given in the instruction. (e.g., `LDA 3000H`, `STA 4000H`).
4. **Indirect Addressing:** The memory address is held in a register pair (usually HL). The register pair acts as a pointer. (e.g., `MOV A, M`, `ADD M`).
5. **Implicit/Implied Addressing:** The operand is hidden or implied by the opcode itself (usually operates on the accumulator). (e.g., `CMA`, `RAL`, `STC`).

### 8.3 Instruction Classification

#### 8.3.1 Data Transfer Instructions
Used to copy data between registers, memory, and I/O. **Flags are NOT affected.**
- `MOV Rd, Rs`: Copy from Source Reg to Dest Reg.
- `MVI R, 8-bit`: Move immediate 8-bit data to register.
- `LDA 16-bit`: Load Accumulator direct from memory.
- `STA 16-bit`: Store Accumulator direct to memory.
- `LXI Rp, 16-bit`: Load 16-bit data into register pair (e.g., `LXI H, 2000H`).
- `LHLD 16-bit`: Load HL pair direct.
- `SHLD 16-bit`: Store HL pair direct.
- `XCHG`: Exchange contents of HL pair and DE pair.
- `IN 8-bit` / `OUT 8-bit`: Input/Output with port.

#### 8.3.2 Arithmetic Instructions
Perform addition, subtraction, increment, decrement. **Flags ARE affected** (except INR/DCR on register pairs do not affect flags).
- `ADD R`: Add register to Accumulator (A = A + R).
- `ADC R`: Add register to A with Carry.
- `ADI 8-bit`: Add immediate data to A.
- `SUB R`: Subtract register from A.
- `SBB R`: Subtract register from A with Borrow.
- `INR R`: Increment register by 1.
- `DCR R`: Decrement register by 1.
- `INX Rp`: Increment register pair by 1 (Does NOT affect flags).
- `DCX Rp`: Decrement register pair by 1.
- `DAD Rp`: Double Add; Add register pair to HL pair (HL = HL + Rp). Affects only Carry flag.
- `DAA`: Decimal Adjust Accumulator (used after BCD addition).

#### 8.3.3 Logical Instructions
Perform AND, OR, XOR, Compare, Rotate.
- `ANA R` / `ANI 8-bit`: Logical AND with A.
- `ORA R` / `ORI 8-bit`: Logical OR with A.
- `XRA R` / `XRI 8-bit`: Logical XOR with A.
- `CMA`: Complement Accumulator (1's complement).
- `CMP R` / `CPI 8-bit`: Compare with A (Performs A - R, sets flags, discards result).
  - If A < R: CY=1, Z=0
  - If A = R: CY=0, Z=1
  - If A > R: CY=0, Z=0
- `RLC`, `RRC`, `RAL`, `RAR`: Rotate left/right (with or without carry).

#### 8.3.4 Branching/Control Instructions
Alter the normal sequential flow of execution.
- **Unconditional:** `JMP 16-bit`, `CALL 16-bit`, `RET`.
- **Conditional:** Check flag status before branching.
  - `JC` (Jump if Carry=1), `JNC` (Jump if Carry=0)
  - `JZ` (Jump if Zero=1), `JNZ` (Jump if Zero=0)
  - `JM` (Jump if Minus/S=1), `JP` (Jump if Positive/S=0)
  - `JPE` (Jump if Parity Even/P=1), `JPO` (Jump if Parity Odd/P=0)
  (Similar conditional `CALL` and `RET` exist, e.g., `CC`, `CNC`, `RC`, `RNZ`).
- `RST n`: Restart (software interrupts 0-7).

#### 8.3.5 Machine Control Instructions
- `HLT`: Halt CPU.
- `NOP`: No operation (creates delay).
- `EI` / `DI`: Enable / Disable Interrupts.
- `SIM` / `RIM`: Set / Read Interrupt Mask.

## 🔍 9. Assembly Language Program Examples

### Example 1: Addition of two 8-bit numbers
**Problem:** Add two 8-bit numbers stored in 2000H and 2001H. Store the sum in 2002H and carry in 2003H.
```assembly
LXI H, 2000H  ; Initialize HL pointer to 2000H
MOV A, M      ; Load first operand into A
INX H         ; Point to next memory location (2001H)
MOV B, M      ; Load second operand into B
MVI C, 00H    ; Initialize C register for Carry
ADD B         ; A = A + B
JNC SKIP      ; If no carry, jump to SKIP
INR C         ; If carry generated, increment C
SKIP: 
INX H         ; Point to 2002H
MOV M, A      ; Store sum
INX H         ; Point to 2003H
MOV A, C      ; Move carry to A
MOV M, A      ; Store carry
HLT           ; Stop execution
```

### Example 2: Finding Largest Number in an Array
**Problem:** Find the largest number in a block of data. Size of block is at 2000H. Array starts at 2001H. Store result at 3000H.
```assembly
LXI H, 2000H  ; HL points to array size
MOV C, M      ; C acts as a counter
DCR C         ; Decrement count (N-1 comparisons needed)
INX H         ; Point to first element
MOV A, M      ; Load first element as initial maximum
LOOP: 
INX H         ; Point to next element
CMP M         ; Compare A with M (A - M)
JNC NEXT      ; If A >= M (No Carry), jump to NEXT
MOV A, M      ; If M > A, update maximum in A
NEXT: 
DCR C         ; Decrement counter
JNZ LOOP      ; If count != 0, repeat loop
STA 3000H     ; Store the maximum value
HLT
```

### Example 3: Multiplication of two 8-bit numbers (Successive Addition)
**Problem:** Multiply two 8-bit numbers at 2000H and 2001H, store 16-bit result at 2002H (LSB) and 2003H (MSB).
```assembly
LXI H, 2000H  
MOV B, M      ; Multiplicand in B
INX H
MOV C, M      ; Multiplier (Counter) in C
LXI H, 0000H  ; HL used to accumulate sum (Product)
MOV A, C      ; Check if multiplier is 0
CPI 00H
JZ STORE      ; If multiplier is 0, product is 0
LOOP:
MOV A, L      ; Add B to HL pair
ADD B
MOV L, A
JNC NO_CY     ; Check for carry to MSB of result
INR H         ; Increment H if carry from L
NO_CY:
DCR C         ; Decrement multiplier
JNZ LOOP      ; Repeat until multiplier is 0
STORE:
SHLD 2002H    ; Store 16-bit result in 2002H and 2003H
HLT
```

## 10. Comparison Table: 8085 vs 8086

| Feature | Intel 8085 | Intel 8086 |
| :--- | :--- | :--- |
| **Data Bus** | 8-bit | 16-bit |
| **Address Bus** | 16-bit | 20-bit |
| **Memory Capacity**| 64 KB ($2^{16}$) | 1 MB ($2^{20}$) |
| **Clock Speed** | 3 MHz - 5 MHz | 5 MHz - 10 MHz |
| **Architecture** | Accumulator-based | General Purpose Register-based |
| **Pipelining** | Not supported | Supported (Instruction Queue) |
| **I/O Capability** | 256 I/O ports (8-bit address) | 65,536 I/O ports (16-bit address) |
| **Multi-processing**| Not supported | Supported (Min/Max modes) |

## 📝 11. Key Formulas Summary

> **Memory Size Calculation:**

$$ \text{Memory Capacity} = 2^N \text{ Bytes} $$
> (Where N = number of address lines)
> For 8085: $2^{16} = 65,536 = 64 \text{ KB}$
>
> **Execution Time Calculation:**

$$ \text{Instruction Execution Time} = (\text{Total T-States}) \times T $$

$$ T = \frac{1}{\text{Clock Frequency}} $$
> Example: An instruction takes 7 T-states at 2 MHz clock.
> Execution Time = $7 \times \frac{1}{2 \times 10^6} = 3.5 \mu s$.

## 💡 12. Common Mistakes / Exam Tips

> [!WARNING]
> **Subtractions and the Carry Flag:** During `SUB` or `CMP`, the Carry Flag acts as a **Borrow Flag**. If $A < R$, a borrow is needed, so CY=1. If $A \geq R$, CY=0.
> 
> **Pointers and Data Sizes:** 
> - `LXI H, 2000H` loads the *address* 2000H into HL.
> - `LDA 2000H` loads the *data* at 2000H into the Accumulator. Do not mix them up!
> 
> **End of Program:** ALWAYS end your assembly programs with `HLT` in exams. Missing it indicates a logical error in hardware flow.
> 
> **DAD Instruction:** `DAD B` adds BC to HL and stores the result in HL. It is the ONLY 16-bit arithmetic instruction that affects the Carry flag in 8085. It does not affect Z, S, P, AC.

## ✏️ 13. Practice Problems

**Q1:** What will be the contents of the Accumulator and Carry Flag after the following sequence of instructions?
```assembly
MVI A, A7H
MVI B, 8BH
ADD B
```
**Solution:**
A7H = 1010 0111
8BH = 1000 1011
Adding them:
  1010 0111
+ 1000 1011
-------------
1 0011 0010
Carry = 1, Sum = 32H.
Accumulator = 32H, Carry Flag = 1.

**Q2:** Identify the addressing mode for the following instructions:
1. `MOV A, M`
2. `LXI SP, FFFFH`
3. `CMA`
4. `LDA 2050H`

**Answers:**
1. Indirect Addressing
2. Immediate Addressing
3. Implied Addressing
4. Direct Addressing

**Q3:** Write a program to mask the lower 4 bits of the contents of the Accumulator and keep the higher 4 bits intact.
**Solution:**
```assembly
; Masking implies using the AND logical operation.
; To clear lower 4 bits and keep higher 4 bits, AND with F0H (1111 0000).
ANI F0H   ; Logical AND immediate data F0H with Accumulator
HLT
```

**Q4:** Differentiate between `JMP` and `CALL` instructions.
**Answer:**
- **JMP (Jump):** Unconditionally transfers control to a new memory location. The return address is NOT saved.
- **CALL:** Transfers control to a subroutine. The return address (address of the instruction immediately following the CALL) is pushed onto the Stack before jumping, allowing return via the `RET` instruction.

**Q5:** Calculate the number of T-states and time required to execute `MVI A, 45H` if clock frequency is 3 MHz.
**Solution:**
`MVI A, 45H` is a 2-byte instruction. It requires Opcode Fetch (4 T) + Memory Read for data (3 T) = 7 T-states.
$T = 1 / 3\text{ MHz} = 0.33 \mu s$.
Time = $7 \times 0.33 \mu s = 2.33 \mu s$.
